# claude-design-improvements

Daily design-intelligence knowledge base, auto-maintained by a Claude cloud routine.

Every day a cloud agent deep-studies 5 premium / award-winning websites (typography,
layout, color, motion — and **why** each decision was made) and updates
[`DESIGN-INTELLIGENCE.md`](./DESIGN-INTELLIGENCE.md):

- **DISTILLED PRINCIPLES** — rolling, build-time design rules (read this before building UI).
- **DAILY LOG** — dated per-site deep analyses, newest on top.

Local Claude Code sessions `git pull` this repo on start so the principles are always fresh.
